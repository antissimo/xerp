### T-Q3. R5: several inactive masters on one posting
`AC36_R5_…` posts a transfer whose source **and** destination are inactive (and no stock exists) and expects one
`REFERENCE_INACTIVE` with both keys `warehouseId` and `toWarehouseId`, as 005/R13 reports the warehouse and the
articles together. If only the first is meant to be reported, the test must change.

### T-Q4. R12: order of checks, as tested
- unknown document + `{}` -> `400` (form before `404`);
- `note` of 2001 characters -> `400` with key `note`;
- a draft + a date in the past -> `INVALID_STATE` (state before date);
- goods already issued + date one day early -> `400` with key `documentDate` (date before stock).

`"lines"` in the reverse body is asserted as `400 VALIDATION_FAILED` with a non-empty `errors`; the key is not
asserted because the criterion names none. Should it be `lines`?

### T-Q6. Readings the tests take where a criterion leaves room
- AC-22 `toWarehouseId` equal to `warehouseId`: `errors` must **not** contain `warehouseId`.
- AC-31 / AC-32: the order "outgoing, then incoming" is asserted per line for a posted transfer. For a
  reversing transfer (AC-56) the order of the two entries of a line is **not** asserted (R14 does not give one).
- AC-51 "otherwise untouched": every property of the original except `status` and `reversedBy` is compared,
  and the property set must be the same. The original's ledger entry is compared before and after too (S2).
- AC-60 "the next posted receipt is `SR-000002`": that receipt goes to W2 with article B, so Stock(A, W1)
  stays 60 and the final reversal can end at 0 as the criterion says.
- AC-62 / AC-63: stock is topped up before the refused operations, so only the state can be the reason;
  AC-63 runs for a receipt, an issue and a transfer.
- AC-66: five postings (receipt of A and B, transfer of three lines, two issues, one more receipt), reversed
  in the order issue, issue, receipt, transfer, receipt; stock equals the ledger after every reversal.
- AC-68: also asserts that the four refused requests burnt no number (the next receipt is `SR-000003`).
- AC-69 (and its transfer variant) runs three rounds with fresh tenants and accepts either winner.
- AC-80: `toWarehouseId` must allow a string and `null` and must not be `required`;
  `stock_document_reverse` is checked for the full annotation tuple of section 5.
